Add a Worker-level daily-cost circuit breaker that short-circuits requests with HTTP 503 once the cumulative estimated spend in the current UTC day reaches `DAILY_COST_LIMIT_MICRO_USD` (default 333,000 microUSD = $0.333/day = $10/month / 30). The README gets a "Cost guardrails" section documenting the cost model, threshold, KV key shape, manual reset, and Analytics Engine monitoring query.

Purpose: Implements the **early warning** half of the two-layer cost defense for REQ-07 ("Cost-bounded — a viral day cannot run up an unbounded bill"). The Worker breaker fires before the Anthropic dashboard cap from 10-01, giving Drew a clean "agent's resting" UX while the dashboard cap stays as the hard wall.
