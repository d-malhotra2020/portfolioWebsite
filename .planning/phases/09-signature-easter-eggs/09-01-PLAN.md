<objective>
Ship a `/whoami` route at `drewmalhotra.com/whoami` that returns Drew's profile as terminal-style HTML for browsers and clean text/JSON for `curl`. Implemented as static files generated at build time from a single canonical source — no server-side content negotiation (GitHub Pages is static-only).

Purpose: Signature easter egg that signals taste to senior engineers who instinctively `curl` a portfolio. Three projections (HTML, JSON, TXT) from one source = the operator-console aesthetic carried into the metadata surface.

Output: A canonical profile module (`src/data/whoami.js`), a build-time generator (`scripts/build-whoami.js`), and three generated static artifacts copied verbatim by Vite into `dist/`.
</objective>
