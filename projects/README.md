# Personal Projects Portfolio

This directory contains 5 comprehensive software projects that demonstrate various aspects of modern software engineering, from IoT systems to AI-powered applications.

## 🏠 Smart Home Automation System
**Directory**: `smart-home-automation/`
- **Tech**: Python, Flask, MQTT, SQLite, WebSocket  
- **Features**: 15+ IoT sensors, mobile/voice control, 30% energy savings, <500ms response time
- **Run**: `cd smart-home-automation && pip install -r requirements.txt && python main.py`
- **Access**: http://localhost:5000
- **Description**: Intelligent home automation system with real-time IoT sensor simulation, automated lighting control, climate management, and energy monitoring dashboard.

## 📊 Financial Data Analysis Tool

- **Tech**: FastAPI, TensorFlow, Pandas, PostgreSQL, Scikit-learn
